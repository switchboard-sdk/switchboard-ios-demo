# SwitchboardiOSDemo

A simple Xcode-based speech-to-text and text-to-speech demo application for iOS.

## Setup

Run the setup script to download all dependencies:

```sh
./scripts/setup.sh
```

This downloads Switchboard SDK 3.2.3 frameworks from S3 into the `libs/` directory.

## Build & Run

Open the `SwitchboardiOSDemo.xcworkspace` in Xcode.
Run the application.
